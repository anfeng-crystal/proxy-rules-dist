RuleForge · sing-box / SFA

原生规则，分类路由与仅域名 DNS 规则分开发布。当前发布 39 / 39 个分类。

分类规则为 source 格式 JSON（版本 3），不是 SRS 二进制。示例配置使用 5 个 .invalid 节点及虚拟密码，不能直接连接。CNIP 单独引用 SagerNet 官方 SRS。

下载本地生成器 · 示例配置 · 使用说明 · 转换报告

生成本地配置

先取得原生 sing-box 节点 JSON，再用 Python 3 在自己的设备本地运行：

python3 generate_sfa.py nodes.json sfa.local.json --rule-base https://anfeng-crystal.github.io/proxy-rules-dist/sing-box

输出包含节点凭据，请勿上传或提交到公共仓库。默认启用 15 个分类，其余分类及广告拦截按需启用。静态检查不代表已通过 sing-box 核心校验或 SFA 实机测试。
